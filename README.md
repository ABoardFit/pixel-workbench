# 도트 작업실

PNG, 스프라이트 시트, GIF를 나란히 비교하고 프레임별로 편집하는 브라우저 작업실입니다. 파일은 브라우저 안에서만 처리하며 서버로 업로드하지 않습니다. 사용자 그림은 저장소에 포함하지 않습니다.

## 사용하기

1. **이미지 열기**로 PNG 또는 GIF를 선택하거나 작업대에 끌어 놓습니다. 시트는 왼쪽의 **스프라이트 시트 열기**에서 프레임 크기·시작 위치·간격을 지정합니다.
2. 각 비교 칸에서 재생·일시정지·한 프레임 이동·슬라이더로 원하는 프레임을 고릅니다. 재생과 프레임 선택은 칸마다 독립적입니다. 실제 편집 캔버스는 가로로 빈틈없이 붙어 있으며 확대·화면 이동을 함께 조절합니다.
3. **옆에 고정**이나 프레임 아래 ＋는 같은 파일의 현재 프레임을 새 비교 칸에 붙입니다. 같은 파일의 같은 프레임을 수정하면 연결된 칸에도 반영됩니다. **복제해 편집**은 독립된 이미지 한 장을 만듭니다. 캔버스 사이의 구분선은 확대해도 1화면픽셀의 얇은 선이며 실제 그림에는 들어가지 않습니다.
4. 연필·직선·지우개·스포이트·채우기로 편집합니다. 직선을 그릴 때 Shift를 누르면 가로·세로·45° 사선으로 고정됩니다. 한 번의 드래그는 한 번의 그리기 실행 취소로 복원됩니다.
5. 직선 도구에서 **룰러(자)**를 고르거나 **R**을 누르면 도트 대신 얇은 비교용 자를 그립니다. 시작·끝은 픽셀 경계에 맞고, Shift로 가로·세로·45°에 고정할 수 있습니다. 여러 캔버스를 가로질러 그을 수 있으며 확대해도 1화면픽셀 두께를 유지합니다. 새 자는 드래그를 시작할 때의 브러시 RGB 색을 사용합니다. 오른쪽 목록에서 숨기기·삭제·모두 지우기를 할 수 있습니다.
6. 기준 프레임의 **실루엣 잡기**를 누른 뒤 다른 칸을 선택하고 **이 칸에 실루엣 추가**를 누릅니다. 앞뒤 순서·색·불투명도·X/Y·배율을 조절하거나 이동 도구로 드래그합니다. 실루엣은 잡은 순간의 스냅샷입니다.
7. **이미지 저장**에서 현재 프레임 PNG, 전체 GIF, 스프라이트 시트 PNG, 비교 PNG를 내려받습니다. **모든 이미지 저장은 원본 프레임 픽셀만 사용합니다. 실루엣·자·캔버스 경계선은 예외 없이 제외합니다.** 비교 PNG는 원본 크기의 칸들을 가로로 여백 없이 붙이며, 높이가 다르면 위를 맞추고 남는 아래쪽을 투명하게 둡니다.
8. **편집 상태 저장**은 이미지·프레임 시간과 비교 칸·실루엣·자의 설정을 작업 파일에 분리해 보관합니다. **편집 상태 열기**로 그대로 이어서 작업합니다. 자와 실루엣이 실제 이미지 픽셀에 합쳐지지 않습니다.

PNG와 편집 상태 파일은 픽셀의 RGBA 값을 보존합니다. GIF는 최대 색 수와 이진 투명도라는 형식의 제한이 있습니다. 이미지 저장 중 색 수나 반투명을 변환한 경우 안내하며, 편집 중인 원본은 변경하지 않습니다. GIF 프레임 시간은 형식에 맞는 10ms 단위로 저장합니다. 칸의 미리보기 재생 속도는 저장한 GIF의 프레임 시간에 영향을 주지 않습니다.

비교 칸은 최대 8개입니다. 그리기 실행 취소·다시 실행은 각 프레임별로 보관하며 프레임당 40회, 전체 약 64MiB까지 유지합니다.

## 단축키

| 키 | 동작 |
| --- | --- |
| P | 화면 이동 |
| B | 연필 |
| L | 직선 |
| R | 룰러(자), 도트가 아닌 화면 비교용 선 |
| E | 지우개 |
| I | 스포이트 |
| F | 채우기 |
| O | 실루엣 이동 |
| Shift + 직선 드래그 | 가로·세로·45° 사선 고정 |
| Space를 누르고 놓기 | 활성 칸 재생·일시정지 |
| Space + 드래그 / 마우스 가운데 버튼 | 붙인 캔버스를 함께 이동 |
| 마우스 휠 | 커서 위치를 기준으로 전체 확대·축소 |
| Alt + 드래그 | 선택한 실루엣 이동 |
| Ctrl/⌘ + Z | 그리기 실행 취소 |
| Ctrl/⌘ + Y / Ctrl/⌘ + Shift + Z | 그리기 다시 실행 |
| Ctrl/⌘ + S | 편집 상태 저장 |

## 개발

Node.js 24와 npm을 사용합니다.

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

`npm run build` 결과는 `dist/`입니다. Vite의 상대 경로 설정으로 GitHub Pages의 프로젝트 경로에서도 동작합니다. 배포 설정은 저장소의 GitHub Actions 워크플로를 사용합니다.

주요 구성:

- `src/App.tsx`: 파일·비교 칸·재생·편집 기록·내보내기 연결
- `src/components/JoinedWorkspace.tsx`: 빈틈없는 연속 캔버스, 공통 이동·확대, 독립 프레임 제어, 도트 편집, 얇은 SVG 자·경계선
- `src/components/Inspector.tsx`: 실루엣 레이어와 프레임 설정
- `src/lib/pixels.ts`: 픽셀 그리기·실루엣·합성·겹침 계산
- `src/lib/formats.ts`: PNG/GIF 읽기·쓰기와 시트 분리
- `src/lib/project.ts`: 편집 상태 저장·복원 및 입력 검증. 자·공유 화면 설정은 선택 필드라 이전 작업 파일도 읽을 수 있습니다.

외부 API나 계정 연결 없이 정적 파일만으로 동작합니다.
